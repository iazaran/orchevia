Orchevia

Orchestrate the AI tools you already use. Describe a task once, inspect the plan as a graph, and execute each step through your installed CLIs — Claude Code, Codex, git, gh, tests. Your CLI accounts. Your machine. No telemetry.

Your first workflow in 5 minutes

  1. Install and open Orchevia. The first-run wizard detects git, gh, claude, and codex, and creates your first agent profiles.
  2. Workflows → Samples… → Plan → Implement → Review → Create. A ready-made graph appears on the canvas.
  3. Select any node to configure its profile, prompt, or timeout. Canvas badges flag problems before you run.
  4. Press ▶ Run. Approve the paused gate, inspect per-node output under Runs, cancel anytime. Opening a workflow never runs it.
  5. Go further: generate flows from a goal with ✦ Generate, save reusable Templates, or schedule nightly runs under Automations.

Local-first, by architecture

Your tools, your auth

Orchevia delegates AI work to CLIs you installed and authenticated. It never asks for model API keys.

Your data stays home

Workflows and runs live in a local SQLite database. Orchevia has no telemetry service; the AI CLIs you choose may contact their providers.

Safe by default

Opening a workflow never executes it. Inspect commands before running; runs are explicit, the active child is stopped on cancel, and authentication stays in your tools. Stored output can contain sensitive data; review it before sharing.

Build from source with Node.js 24+, pnpm 10+, Rust stable, and the platform dependencies in the development guide. 

git clone https://github.com/iazaran/orchevia.git
cd orchevia
pnpm install
pnpm tauri dev

pnpm dev opens the browser demo with a local mock backend; pnpm tauri dev runs real workflows in the desktop app. See the development guide.

Build and contribute

The React editor in src/ talks to a typed backend interface. pnpm dev uses its mock so contributors can work on the UI without launching native processes. The Tauri commands in src-tauri/ delegate execution, validation, scheduling, and SQLite storage to crates/core/.

Start with the development guide, architecture, and workflow schema. Run pnpm check, cargo test -p orchevia-core, cargo clippy -p orchevia-core --all-targets -- -D warnings, cargo fmt --check, and cargo check -p orchevia before opening a PR. GitHub Actions also builds installers on PRs and publishes downloads from version tags.
